## 🔧 التخصيص

### **تغيير الألوان:**
عدّل `css/variables.css`:
```css
--color-primary: #YOUR_COLOR;
--color-secondary: #YOUR_COLOR;
```

### **تغيير الإحصائيات:**
عدّل `data-target` في HTML:
```html
<div class="stat-number" data-target="YOUR_NUMBER">0</div>
```

### **إضافة مشروع:**
انسخ بطاقة مشروع موجودة وعدّل:
```html
<div class="project-card-modern project-card" data-category="YOUR_CATEGORY">
    ...
</div>
```
